Quick Reference

Webhook Endpoints

All webhook receiver URLs follow a consistent pattern. Replace yourdomain.com with your actual domain.

Provider Webhook Endpoint Signature Verification
Stripe https://yourdomain.com/webhooks/stripe Stripe-Signature header (HMAC-SHA256)
PayPal https://yourdomain.com/webhooks/paypal PayPal certificate-based verification
Coinbase https://yourdomain.com/webhooks/coinbase X-CC-Webhook-Signature (HMAC-SHA256)
Ko-fi https://yourdomain.com/webhooks/kofi Verification token matching
Patreon https://yourdomain.com/webhooks/patreon X-Patreon-Signature (HMAC-MD5)

Two-Tier Payment Architecture

Understanding Payment Levels: SIGNula supports a flexible two-tier payment architecture. Each payment provider guide includes specific instructions for all levels below.

Level 1: Vendor / Platform

The SIGNula platform owner configures payment providers globally. All transactions process through the platform's own merchant accounts. Configured in the Admin Dashboard.

Level 2a: Partner (Own Keys)

Partners supply their own payment provider API keys. Payments go directly to the partner's account. Best for partners who want full control over their payment flow.

Level 2b: Partner (Platform Keys)

Partners use the platform's payment keys with transaction tracking and automated revenue sharing. Simpler setup but the platform processes payments on behalf of the partner.
