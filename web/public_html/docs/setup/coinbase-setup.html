Coinbase Commerce Setup

Accept cryptocurrency payments (BTC, ETH, USDT, USDC and more) through Coinbase Commerce. Customers pay on a Coinbase-hosted checkout page and SIGNula is notified via webhook.

Overview

Coinbase Commerce is a cryptocurrency payment processor that enables merchants to accept payments in Bitcoin (BTC), Ethereum (ETH), Tether (USDT), USD Coin (USDC), and other supported digital currencies. Unlike traditional payment gateways, Coinbase Commerce uses a hosted checkout model where users are redirected to a Coinbase-hosted payment page.

Tip: Coinbase Commerce is a separate product from the main Coinbase exchange. You can link your existing Coinbase account to automatically convert received crypto to fiat currency if desired.

Integration Type

Model: Hosted Checkout + Webhooks
API: REST API with JSON payloads
Authentication: API Key via X-CC-Api-Key header
Webhook Verification: HMAC-SHA256 via X-CC-Webhook-Signature header

Prerequisites

  • A Coinbase account (personal or business) at coinbase.com
  • A Coinbase Commerce account at commerce.coinbase.com
  • A publicly accessible HTTPS endpoint for webhooks
  • SIGNula Admin Panel access (for vendor setup) or Partner Dashboard access (for partner setup)
  • A cryptocurrency wallet connected to your Coinbase Commerce account for receiving payments

Part A: Vendor (Platform Owner) Setup

Follow these steps if you are the SIGNula platform owner and want to accept crypto payments directly into your own Coinbase Commerce account.

1

Create a Coinbase Commerce Account

Visit commerce.coinbase.com and create an account (or sign in with your existing Coinbase account). Coinbase Commerce is a separate product from the main Coinbase exchange, specifically designed for merchant payments.

Tip: You can link your existing Coinbase exchange account to automatically convert received crypto to fiat currency if desired.
2

Generate an API Key

Once logged in to your Coinbase Commerce dashboard:

  1. Navigate to Settings in the left sidebar.
  2. Click the API Keys tab.
  3. Click Create an API Key.
  4. You may be asked to confirm via two-factor authentication.
Critical: Your API key is shown only once. Copy it immediately and store it securely. If you lose it, you will need to generate a new one.
3

Copy the API Key

Copy the generated API key string. It will look similar to this format:

xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

Keep this key in a secure location such as a password manager. You will enter it into SIGNula in a later step.

4

Set Up Webhook Subscription

Webhooks allow Coinbase Commerce to notify SIGNula when payment events occur (e.g., charge confirmed, charge failed).

  1. In the Coinbase Commerce dashboard, go to Settings.
  2. Click the Webhook subscriptions tab.
  3. Click Add an endpoint.
  4. Enter your webhook URL: 
    https://yourdomain.com/webhooks/coinbase
  5. Click Save.
  6. Copy the Webhook Shared Secret that is generated. This is used to verify that incoming webhooks are genuinely from Coinbase Commerce.
Important: The Shared Secret is critical for webhook security. SIGNula uses it to verify the X-CC-Webhook-Signature header via HMAC-SHA256.
5

Configure SIGNula Admin Panel

Now enter your credentials into SIGNula:

  1. Log in to your SIGNula Admin Panel.
  2. Navigate to Admin → Payments → Providers → Cryptocurrency.
  3. Paste your API Key into the corresponding field.
  4. Paste your Webhook Shared Secret into the corresponding field.
6

Enter API Key and Webhook Secret

Both the API Key and Webhook Shared Secret are stored encrypted in the SIGNula database (fields marked as isSensitive). Double-check that you have pasted the complete values without any leading or trailing whitespace.

Security: Both credentials are automatically encrypted at rest using SIGNula's built-in cryptographic encryption with salt, and are only decrypted when needed for API calls or webhook verification.
7

Select Supported Currencies

Choose which cryptocurrencies you want to accept. The default supported currencies are:

Bitcoin
BTC
Ethereum
ETH
USDT
Tether
USDT
USDC
USD Coin
USDC
8

Optional: Set Crypto Payment Discount

You can optionally set a percentage discount for customers who pay with cryptocurrency to incentivise adoption (e.g., 5% off). Set the discount percentage in the payment.crypto.crypto_discount field, or leave it at 0 to disable.

9

Test Connection and Enable

Click the Test Connection button in the SIGNula admin panel. This will:

  • Make an authenticated API call to Coinbase Commerce to verify the API key.
  • Confirm the webhook endpoint is reachable.
  • Display a success or error message with details.
# SIGNula internally performs a request like:
curl -X GET https://api.commerce.coinbase.com/charges \
  -H "X-CC-Api-Key: YOUR_API_KEY" \
  -H "X-CC-Version: 2018-03-22" \
  -H "Content-Type: application/json"

Once the test passes, toggle the Enabled switch to activate Coinbase Commerce as a payment provider.

Success: If the test passes, Coinbase Commerce is ready to accept cryptocurrency payments on your platform.

Part B: Partner Setup

If you are a partner integrating with SIGNula's multi-tenant payment system, you will need to obtain your own Coinbase Commerce credentials.

1

Obtain Your Own Coinbase Commerce Account

Each partner must create their own Coinbase Commerce account at commerce.coinbase.com and generate their own API key and webhook secret following the same steps in Part A.

2

Enter Credentials in Partner Dashboard

In your SIGNula Partner Dashboard, navigate to Settings → Payment Providers → Cryptocurrency and enter:

  • Your Coinbase Commerce API Key
  • Your Webhook Shared Secret
  • Configure your webhook URL (SIGNula provides a partner-specific endpoint)
Note: Partner webhook URLs follow the pattern: https://yourdomain.com/webhooks/coinbase/{partner_id}
3

Revenue Sharing

Payments received via your Coinbase Commerce account are deposited directly into your crypto wallet. SIGNula manages subscription activation and tier assignment based on webhook confirmations. Revenue sharing (if applicable) is handled separately via the SIGNula Partner billing system.

Webhook Configuration

Coinbase Commerce sends webhook notifications for the following charge events. SIGNula processes these automatically.

Event Description SIGNula Action
charge:created A new charge has been created Logs the charge; marks payment as pending
charge:confirmed Payment has been confirmed on the blockchain Activates subscription / credits account
charge:failed Charge has expired or failed Marks payment as failed; notifies user
charge:pending Payment detected but awaiting blockchain confirmations Updates status to pending confirmation
charge:resolved Charge has been resolved (manually or automatically) Finalises payment record

Webhook Verification (HMAC-SHA256)

Every webhook from Coinbase Commerce includes a X-CC-Webhook-Signature header. SIGNula verifies this using HMAC-SHA256 with your Webhook Shared Secret. 

// Webhook verification in PHP (simplified)
$payload    = file_get_contents('php://input');
$sigHeader  = $_SERVER['HTTP_X_CC_WEBHOOK_SIGNATURE'] ?? '';
$secret     = $decryptedWebhookSecret; // Retrieved & decrypted from tblSettings

$expectedSig = hash_hmac('sha256', $payload, $secret);

if (!hash_equals($expectedSig, $sigHeader)) {
    // Signature mismatch - reject the request
    http_response_code(401);
    exit('Invalid signature');
}

// Signature valid - process the event
$event = json_decode($payload, true);

Troubleshooting

Test Connection fails with "Invalid API Key"

  • Verify you copied the entire API key string without leading/trailing spaces.
  • Ensure the API key has not been revoked in the Coinbase Commerce dashboard.
  • Try generating a new API key and updating the setting in SIGNula.
  • Check that you are using a Coinbase Commerce API key, not a regular Coinbase Exchange API key.

Webhooks are not being received

  • Confirm your webhook URL is publicly accessible (not behind a firewall or VPN).
  • Ensure your server returns a 200 OK response within 30 seconds.
  • Check your server's access logs for incoming POST requests from Coinbase.
  • Verify SSL/TLS is correctly configured (webhooks require HTTPS).
  • Check the SIGNula activity log for any webhook processing errors.

Webhook signature verification fails

  • Ensure the Webhook Shared Secret in SIGNula matches exactly what is shown in Coinbase Commerce.
  • Verify you are reading the raw request body (php://input) without any modifications.
  • Check that no middleware or proxy is modifying the request body before it reaches SIGNula.
  • The signature is computed as HMAC-SHA256(raw_body, shared_secret).

Payment confirmed but subscription not activated

  • Check the SIGNula activity log for the charge:confirmed event.
  • Verify the metadata in the charge contains the correct user_id and plan_id.
  • Ensure the user account exists and is not suspended.
  • Check that the payment amount matches the expected plan price.

Crypto discount not being applied

  • Verify payment.crypto.crypto_discount is set to a value greater than 0.
  • Ensure the discount is applied at charge creation time (the displayed price on the Coinbase page should already reflect the discount).
  • Check that the cryptocurrency being used is in the supported_currencies list.

Reference

API Details

Property Value
API Base URL https://api.commerce.coinbase.com
API Version Header X-CC-Version: 2018-03-22
Authentication X-CC-Api-Key: YOUR_API_KEY
Content Type application/json
Webhook Signature Header X-CC-Webhook-Signature
Webhook Signature Algorithm HMAC-SHA256

Settings Reference (tblSettings)

Fields marked with are encrypted at rest (isSensitive = true).

Setting Key Type Description
payment.crypto.enabled Boolean Enable or disable Coinbase Commerce as a payment provider
payment.crypto.api_key String Your Coinbase Commerce API key (encrypted, isSensitive)
payment.crypto.webhook_secret String Webhook shared secret for signature verification (encrypted, isSensitive)
payment.crypto.supported_currencies JSON JSON array of accepted cryptocurrency symbols.
Default: ["BTC","ETH","USDT","USDC"]
payment.crypto.crypto_discount Decimal Percentage discount for crypto payments (e.g., 5.00 for 5%). Set to 0 to disable.
