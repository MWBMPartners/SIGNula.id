# Device-wide rule: AI-tool fallback (copy onto every machine you use)

Copy the block below into **both**:
- `~/.claude/CLAUDE.md`  (Claude Code, all projects on this device)
- `~/.codex/AGENTS.md`   (Codex, all projects on this device)

---

## AI-tool fallback (all projects)
If one AI service (Claude Code, Codex, or any other) or its helper agents becomes
unavailable or runs out of credit, hand the work to another suitable AI tool when that can
be done without losing context or progress. Switch back to the main tool as often as
possible, and once it is available again run a full review of the work done meanwhile.
Work is cross-checked by a different AI anyway, which makes this safe — but it means each
project's handoff document must be kept up to the minute. No specific tools are required;
use whatever suitable tool is available.

## Plain English (all projects)
Explain things in plain, everyday English without technical jargon.
